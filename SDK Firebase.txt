CONFIGURACIÓN FIREBASE - GOLAZO
===============================

Este archivo documenta la configuración de Firebase del proyecto.
La API key de Firebase Web NO es un secreto: está diseñada para ser
pública en apps web (se incrusta en el código del navegador).

La seguridad real se logra con:
1. Firebase Realtime Database Security Rules (reglas de la base de datos)
2. Firebase App Check (verificación de la app)
3. Restricciones de la API key en Google Cloud Console (por dominio)

------------------------------------------------------------
REGLAS RECOMENDADAS - REALTIME DATABASE (database.rules.json)
------------------------------------------------------------
{
  "rules": {
    "usuarios": {
      "$uid": {
        ".read": "auth != null",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}

------------------------------------------------------------
REGLAS RECOMENDADAS - FIRESTORE (firestore.rules)
------------------------------------------------------------
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
