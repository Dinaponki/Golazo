🔒 CONFIGURACIÓN DE FIREBASE PARA GOLAZO
==========================================

⚠️ IMPORTANTE - SEGURIDAD ANTES QUE NADA
-----------------------------------------
NUNCA subas la API Key real a un repositorio público. GitHub Secret Scanning
detecta automáticamente las Google API Keys expuestas. Si ya fue detectada,
debes rotarla inmediatamente.

PASOS PARA ELIMINAR EL LEAK:
1. Rotar la API Key en Google Cloud Console → APIs & Services → Credentials.
2. Restringir la API Key con "HTTP referrers" (solo tu dominio: *.tudominio.com).
3. Regenerar el archivo de configuración en Firebase Console → Project Settings.
4. Cerrar el Secret Scanning Alert en GitHub marcándolo como "revoked".
5. Borrar el historial de Git que contiene la key: `git filter-repo` o `BFG Repo-Cleaner`.
6. Revonar la base de datos: revisar logs de acceso en Realtime Database → Usage.

NOTA: La API Key en apps web de Firebase NO es un secreto criptográfico. La
seguridad real proviene de las Firebase Security Rules, no de la API Key.
Sin embargo, una key expuesta puede ser usada por terceros para consumir
recursos (quota hijacking). Por eso es importante restringirla por dominio.

// Las reglas deben estar en modo "restricción predeterminada"
// y luego abrir selectivamente según las necesidades del juego.
// Esto evita que alguien con la API key escriba libremente.

{
  "rules": {
    "usuarios": {
      "$uid": {
        // El usuario solo puede leer/escribir su propio nodo
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid",
        // Subida individual de campos (nickname, stats, etc.)
        "nickname": { ".validate": "newData.isString() && newData.val().length >= 0 && newData.val().length <= 12" },
        "descripcion": { ".validate": "newData.isString() && newData.val().length <= 200" },
        "redSocial": { ".validate": "newData.isString() && newData.val().length <= 200" }
      }
    },
    // Ranking: lectura pública, escritura restringida a usuarios autenticados
    "ranking": {
      ".read": true,
      ".write": "auth != null"
    },
    // Partidas online 1vs1: solo usuarios autenticados pueden crear/unirse
    "partidas": {
      "$codigo": {
        // Cualquier usuario autenticado puede leer una partida (para unirse)
        ".read": "auth != null",
        // Solo usuarios autenticados pueden crear/modificar partidas
        ".write": "auth != null",
        // Validaciones de estructura
        "codigo": { ".validate": "newData.isString() && newData.val().length === 6" },
        "creador": {
          "uid": { ".validate": "newData.isString()" },
          "nickname": { ".validate": "newData.isString() && newData.val().length <= 20" },
          "fotoURL": { ".validate": "newData.isString()" },
          "listo": { ".validate": "newData.isBoolean()" }
        },
        "unido": {
          "uid": { ".validate": "newData.isString()" },
          "nickname": { ".validate": "newData.isString() && newData.val().length <= 20" },
          "fotoURL": { ".validate": "newData.isString()" },
          "listo": { ".validate": "newData.isBoolean()" }
        },
        "estado": { ".validate": "newData.isString() && (newData.val() === 'esperando' || newData.val() === 'jugando' || newData.val() === 'terminada')" },
        "creadoEn": { ".validate": "newData.isNumber()" },
        "ultimaActividad": { ".validate": "newData.isNumber()" }
      }
    },
    // Cola de matchmaking para "Jugar rápido": solo usuarios autenticados
    // Cualquier usuario autenticado puede leer/escribir porque es una cola
    // temporal donde los jugadores se eliminan mutuamente al emparejarse.
    // IMPORTANTE: el '.read' y '.write' deben estar TAMBIÉN a nivel padre
    // para que get(ref(db, 'cola_rapido')) funcione, no solo en $uid.
    "cola_rapido": {
      ".read": "auth != null",
      ".write": "auth != null",
      "$uid": {
        "uid": { ".validate": "newData.isString()" },
        "nickname": { ".validate": "newData.isString() && newData.val().length <= 20" },
        "fotoURL": { ".validate": "newData.isString()" },
        "partidaId": { ".validate": "newData.isString() && newData.val().length === 6" },
        "creadoEn": { ".validate": "newData.isNumber()" }
      }
    }
  }
}
