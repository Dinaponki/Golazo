📖 ¿Cómo se anota? (recordatorio rápido)
✔ Ganar una ronda: +1 estrella (⭐)
✔ 🥅 Penal rechazado / ⚽ Gol rechazado: +1 estrella
✔ ⭐ Golazo rechazado / 📺 VAR ganado: +2 estrellas
✔ 🥅 Penal atajado / ⚽ Gol defendido: +2 estrellas

👉 Tocá una estrella para encenderla. Con las 3 encendidas, el gol se anota solo.
👉 Tocá la misma estrella marcada para bajarla (si bajás de 3, se quita el gol).
👉 Tocá cualquier fila para seleccionarla y anotar o corregir sus estrellas ahí.
👉 También podés usar los botones ⚽ Gol A / Gol B sobre la fila elegida.
👉 Un gol por fila y el partido dura 9 filas (90').

El marcador se guarda solo en este dispositivo.
